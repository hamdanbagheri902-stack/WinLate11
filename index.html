  1. Start the machine. GRUB shows for about a second, then the splash screen, then the desktop.
  2. Click inside the window to capture the mouse. Press Right Ctrl to release it.
  3. Open the Start menu with the button or the Windows key, and just type to search.

On a real PC

Steps

  1. Use a spare USB stick. Everything on it is erased.
  2. Write the ISO to it with Rufus (choose DD Image mode) or balenaEtcher.
  3. Open the boot menu (often F12, F10 or Esc) and pick the stick.
  4. Boot in Legacy / BIOS / CSM mode, not UEFI.

What to expect

  • UEFI-only PCs can't boot it.
  • It reads the keyboard and mouse as PS/2. A USB mouse works only if the BIOS offers Legacy USB Support.
  • It has no disk driver, so it never touches the PC's drives.
  • Untested on real hardware. If it fails, a black screen is the likely result.

Build from source

On Ubuntu or Windows with WSL (Ubuntu). It produces winlite11.iso in the project folder.

sudo apt update
sudo apt install -y build-essential grub-pc-bin grub-common xorriso mtools python3 unzip
unzip winlite11-src.zip && cd winlite11
chmod +x build.sh && ./build.sh

Layout: boot/ kernel/ drivers/ gui/ fs/ apps/. The README in the zip covers tests and the roadmap.

Known limits

  • PS/2 keyboard and mouse only. No USB, no scroll wheel, no tablet pointer.
  • Everything runs inside the kernel: no user mode and no separate processes.
  • No disk driver. The file system lives in RAM.
  • Fixed 1024×768 screen. Software drawing, so dragging can feel slow on a slow host.
  • ASCII text only. No networking or sound.
